# OpusClip logged-in tour, part 2: account & sidebar pages (Oct 25 2026, trial)

## Avatar menu (top-left "w" button)
Accounts (email + Trial badge) / Subscription / Credit usage history / Language submenu / LinkedIn capabilities / OpusClip AI Producer (Beta) / OpusClip Thumbnail / Go to Agent Opus / Logout. No standalone profile or notification-preferences page found. Notifications bell in top bar.

## /subscription
"Free trial (Pro plan)" Active + Upgrade. Credits & features: balance (plan / trial / top-up credits), expiry date + "See details" -> Credit breakdown dialog (Source, Expires, Remaining; "Credits closest to expiry are always used first"). Seats 1/1, brand templates 2/2. Billing & payment: next-cycle credits, trial end, billing info.
Credit usage history table: Date, Usage, Details, Status, Credits (e.g. ClipProject, file name, Used, -1); page size + pager.

## Upgrade dialog (from Upgrade, Add credits, Invite members)
Monthly / Yearly (up to 50% off). Starter $15/mo, 150 credits (clipping + virality score, animated captions 20+ langs, auto-post/download, editor, 1 brand template, filler/silence removal, no watermark). Pro (most popular) $29/mo or $14.50/mo yearly ($174): 300 credits/mo, rollover 2 months, 2 seats (to 4), 2 brand templates (to 4), 6 social connections (to 12), AI image B-roll, 10+ input sources, Premiere/DaVinci export, multiple aspect ratios, scheduler, custom fonts, speech enhancement, subtitle/transcript downloads. Business: Contact us (priority processing, custom credits/seats, storage, API, MSA, Slack, security). "Compare all features and plans". Change plan dialog: plan dropdown + credit pack dropdown, Stripe checkout. Top-ups locked on trial. Team invites are paywalled (Pro).

## /projects
Tabs All / Collections / Projects. Collections: Add new collection (name dialog), Favorites. Project cards: Upload new video tile; card with New tag, "Unsaved • 6 days left to edit", title, clip count, date. Storage 0/100 GB, Auto-save (paid) and Auto-import chips.
Project "..." menu: Save to storage, Share project, Add to a collection, Download subtitles (SRT), Download transcript (TXT), Delete.
Auto-import: "Auto-import videos from YouTube" - connect YouTube account; credits by full video length.

## /brand-templates-ux
First-run wizard (3 steps, step 1 aspect ratio 9:16/1:1/16:9/4:5). Template editor: Save template, demo preview; sections: Style (clip layout fill/fit/three/four/split; caption font), Auto headline style, Brand (overlay logo + CTA, intro/outro, music), AI toggles (remove filler words, remove pauses, keyword highlighter, AI emojis, stock video B-roll, auto transitions, auto zoom).

## /brand-kits (Asset library)
Storage meter; Censored words list (Beta, default curse words, add list); Brand vocabulary 0/30 (proper nouns for transcription); Fonts 0/2 upload; Media (All/Images/Videos/Audio, upload).

## /auto-post/calendar
Calendar Beta intro; month grid, Schedule post, Upload local video, timezone chip. Schedule post -> Select project dialog (OpusClip / Agent Opus tabs, project filter, upload own video, project cards with days-to-expiry).
