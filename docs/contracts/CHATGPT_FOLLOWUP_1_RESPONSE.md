## Producer contract delta for the skill owner (no skill files edited)

1. \`GET {jobUrl}/renders\` now also works for \`finish_clip\` jobs, scoped to their one clip. It returns clip \`status\` queued/rendering/done/failed and media URLs after done. **GET never enqueues or retries paid work**. A missing render row before enqueue is queued, not failed; an explicit enqueue failure records a redacted error.
2. \`POST {jobUrl}/renders\` for standalone \`finish_clip\` accepts \`{clipId?,editsJson}\` referencing a newly committed named artifact. \`clipId\` defaults to the current revision clip. New edits increment the native version and render only that clip. Byte-equivalent edits reuse the existing result; on a legacy never-server-rendered clip, a first unchanged submission queues one full render. Failed output requires corrected edits.
3. \`POST {jobUrl}/complete\` accepts **no MP4** after the standalone render is done, but requires a committed \`job.json\` and stores its normalized \`costReport\`. Discovery \`/complete\` remains gated on every published clip render succeeding.
4. \`clip_and_finish\` dispatch persists \`maximumClips\` (1–30 in producer mode, 1–10 legacy); \`GET /inputs\` passes it through in \`clipCount\`. The UI now exposes up to 30.
5. BYO production brief can explicitly contain \`narration.mode:'none'\` and \`narration.handling:'no_narration'\`; optional \`voiceoverAmount:'none'|'occasional'|'mostly'\`, \`reviewPlan:boolean\`, \`captionsEnabled:boolean\`, \`goal:string\`, \`footageType:string\`, \`callToAction:string\`, plus existing audience and source instructions. **Omitted** keys stay omitted for existing films.
6. Uploaded media role \`angle\` and role \`broll\` now mean \`use_as_picture\` and never imply narration. \`talking_head\` keeps legacy semantics.
7. \`clip_jobs.payload.audioMeasurements\` is populated after verified final audio: \`{integratedLufs,truePeakDbtp,targetLufs,verified:true}\`. The producer should compare actual delivered output with the targets; not merely rely on the filter being configured.
8. The standalone BYO UI is gated and currently takes the in-app \`DOC_PLAN\` checkpoint route instead of immediately dispatching a producer-bot edit; **do not assume** producer webhook jobs pause for plan review. That bridge belongs to the next A6 integration.

## A6 proposal — films as native editable tracks (design only; no A6 code in this branch)

1. **One canonical edit document.** Define a versioned native \`ClipEditsV2\` composition with unique immutable customer-media source IDs, actual source ranges and project-time segments. Retain the portable scene runtime for graphics but represent each editable element in the shared timeline rather than treating a pre-rendered master as the sole source.
2. **Document-to-editor mapper.** Build a deterministic adapter from \`transovo.motion-project/1\` scene/asset/timeline records and \`motion-studio-portable/1\` manifests to \`sources\`, project-time segments, cut list, caption/text/graphics/audio/keyframes. Reject unsupported elements with an actionable error—never silently bake them into the editor master.
3. **Overlay alignment over every file.** Replace the current base-render-then-splice inserts model for native films with unified project-time placements, so titles, graphics, captions, audio and B-roll can cover second and later source files. Preserve original speaker and word offsets with file-qualified IDs.
4. **One render graph.** Browser preview and server export consume the same normalized graph. For long work, split by independent scene/range, include dependencies and source identities in content hashes, render segment jobs in bounded parallel workers and assemble losslessly where formats permit; only invalidated segments rerender.
5. **Revisions in place.** Use optimistic \`editsSaveVersion\` plus \`ClipEditVersion\` snapshots; split producer-owned vs user-owned nodes, carry user edits forward or surface conflicts. Do not overwrite a user's manual title, timing or angle swap on reimport.
6. **Gated migration and B0 proof.** Existing idea/script film output and clipper remain byte-equivalent with BYO off. Add fixtures for original source reuse, 4-file overlays/captions/VO, round-trip, 30–60 min export and loss/restart. Flip \`FEATURE_BYO_V1\` only after end-to-end content and actual preview/export/audio parity are certified.
