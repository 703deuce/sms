## Researched but left out (couldn't be verified)
- **"63% of the highest-CTR TikToks hook in 3 s."** Widely quoted, but no TikTok primary found. TikTok's own guidance (3 s proposition / 6 s hook) is used instead.
- **Meta "captions raise view time 12%" and "41% watched without sound."** The Meta business pages timed out repeatedly, so the figures were omitted.
- **YouTube −14 LUFS.** Widely measured but not published by YouTube. No published TikTok or Instagram loudness target exists.
- **No authoritative number found** for face size as a % of frame, maximum font count, emoji use, progress bars, or sports replay counts. These are left as Freedom or design judgement.
- **Netflix's mix spec** (−27 LKFS dialogue-gated, −2 dBTP) was seen only in a search summary. Not used.
