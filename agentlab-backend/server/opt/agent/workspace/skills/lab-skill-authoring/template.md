# SKILL.md template

```
---
name: lab-example-slug
when_to_use: Use when <the job that should attach this>. Not for <nearby jobs this must not steal>.
description: One short blurb.
---

# Title

When to follow this, in a few sentences.

## Steps

- Concrete commands and checks, not wishes.
- Where the deliverable goes (usually `out/`).

## Don't

- Exclusions and safety (no secrets, no bookings, no rewriting AGENTS.md, …).
```

`when_to_use` is what the Haiku router sees (first 220 characters). Put the triggers and the exclusions in that one line.
