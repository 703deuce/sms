## Operating the page

- **JavaScript-heavy pages: screenshot, don't keep rewriting scrapers.** If a page is JavaScript-heavy, or a fetch or scrape returns little or no usable data, call `agent_load_browser` if the browser tools are not loaded yet, open it in the browser, take a screenshot (`browser_shot` / `browser-shot`), and read the values off the image with your own vision (`agent_view`). Scroll and screenshot again if more of the page is needed. DeepSeek Pro gets the vision fallback automatically (`look`). Do not pay for a scraping service.
- `browser-shot [out.png]` saves a screenshot of the page your browser tools are on right now (same tab, same logged-in state); `browser-shot out.png --url URL` captures a URL in a separate headless browser. Then `agent_view` it (or `look out.png "..."` if text-only).
- **When the browser's text view is unclear, look at the screen.** The browser tools give you a text/accessibility view of the page. When that view is unclear or incomplete — canvas or WebGL UIs, video players, captchas, image-heavy pages, maps, editors — or an action didn't do what you expected (nothing changed, wrong page, a popup appeared), take a screenshot with `browser-shot shot.png` and look at it: the `agent_view` tool on shot.png if your model can see (always), otherwise `look shot.png "What is on screen? Is there a popup? Where exactly should I click?"`. Then act and check again.
- **Fill every form field you can.** When filling a form, fill every required field and every field the task gives a value for, or that has an obvious sensible value. Don't skip fields as optional. After filling, read the values back, and if one didn't stick, retry it in the control's native format (for example HH:MM for time, YYYY-MM-DD for date, digits for tel).


**Every run and helper has its OWN browser**, like its own computer: a private Chromium on its own 1920x1080 display with its own tabs, started the first time you use it. It begins signed in to everything the shared browser is signed in to (its profile and live cookies are copied from the shared one), keeps the same proxy, timezone/location and image blocking, and no other conversation can touch its tabs or screen. Your `browser_*` tools, `browser-shot`, `browser-upload`, `captcha-solve`, `desktop-open`, `desktop-shot`, `click`, `drag`, `scroll`, `zoom`, `key`, `desktop-type` and `vision-act` all act on YOUR browser. `job-browser` shows it (`job-browser shot out.png` screenshots it); it closes after 15 idle minutes and reopens on next use, and is deleted when the run ends. Downloads land in `/workspace/desktop/jobs/<conversation id>/downloads` (the `downloads` path `job-browser` prints): copy what you need into your job folder.
- **`browser_*` tools (Playwright):** `browser_navigate url`, `browser_snapshot` (the page's text/accessibility tree with `ref=` ids; actions only link a snapshot file in `.browser/`, so call `browser_snapshot` when you need to read the page), `browser_click ref`, `browser_type ref text`, `browser_fill_form`, `browser_select_option`, `browser_press_key`, `browser_hover`, `browser_drag`, `browser_wait_for`, `browser_tabs` (list/new/select/close), `browser_navigate_back`, `browser_evaluate`, `browser_file_upload`, `browser_handle_dialog`, `browser_find`, `browser_take_screenshot` (saved under `.browser/`, not shown to you: `agent_view` that file), `browser_console_messages`, `browser_network_requests`. Refs come from the latest snapshot.
- **Logins: the shared browser is the source of truth.** Rick's sign-ins live in the shared persistent browser (profile `/workspace/desktop/chrome-profile`, CDP 127.0.0.1:9222, the one on the Live screen). Nothing you log into in your own browser is kept after the run unless you run `job-browser save-logins example.com` (copies that site's cookies into the shared browser). After Rick signs in on the shared browser, `job-browser sync` copies the fresh logins into yours (`handoff` does this for you). `desktop-open --shared URL` and `desktop-reset --shared` act on the shared browser; `DESKTOP_SHARED=1 <command>` makes any desktop command use it. Chat conversations that are not runs still use the shared browser for everything.
- In your own browser there is no address bar or window chrome (kiosk): screenshots show exactly the page at 1920x1080, so screenshot pixels are click pixels. `key ctrl+r`/`F5` reloads, `alt+Left` goes back, `ctrl+t`/`ctrl+w` open/close a tab; to change the URL use `desktop-open URL` or `browser_navigate`. `desktop-reset` closes your tabs; `desktop-reset --hard` restarts your browser.

## Blocked pages

Your browser goes direct first. If a page's response is blocked (HTTP 403/429/451, a Cloudflare/bot challenge header, or a failed connection), the egress hook automatically switches that site to the residential proxy, cuts the old connection and reloads the tab (same tab, cookies kept). If `browser_navigate` showed status 403 or "Just a moment...", wait about 10 seconds, then `browser_snapshot` or navigate again before calling the site blocked. Report which tiers were tried; usage and caps: `egress-usage`.
