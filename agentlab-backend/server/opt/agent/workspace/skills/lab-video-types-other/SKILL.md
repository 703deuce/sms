# Type playbook: other kinds

Name the kind in `log/job.md`, then borrow the nearest standards; the all-types checklist (C0, `lab-video-review`)
always applies. If the film is mostly one named type, use that playbook's page instead (load it by name:
`lab-video-types-documentary`, `-news-explainer`, `-product-brand`, `-music-culture`, `-sports`, `-podcast-interview`).

How kinds map onto the playbooks:
- **True crime, history, biography:** 2.4.
  - Hedges kept; recreations labelled (honesty rule).
  - No frankenbites [HSM-8].
- **Data story:** 2.4 plus 2.2. Every on-screen number sourced; hold data cards until read (≈ 0.3 s/word); one data point per card.
- **Explainer / tutorial:** 2.2 plus 2.6.
  - Tease the end result first, then show the process [TT-CA1].
  - Wistia: 1–5 min for education [WISTIA].
- **SaaS demo, launch/ad, promo, logo sting:** 2.6.
- **Social short / kinetic type:** 2.2 caption and safe-zone rules. Text overlays capped at BBC/Netflix reading rates unless the words are also spoken.

**Must** (every kind): the hook lands in the first 3 s (90 f); text inside the safe area and readable at broadcast
reading rates unless the words are also spoken; TP <= -1 dBTP; the C0 checklist passes on the change-point stills.
