# Public job-board URL patterns

These are starting points for a public search. Open a concrete listing page before you cite it.

- Indeed: `https://www.indeed.com/jobs?q=QUERY&l=LOCATION`
- Wellfound (AngelList): `https://wellfound.com/role/r/QUERY` or site search for the role
- USAJOBS: `https://www.usajobs.gov/Search/Results?k=QUERY`
- We Work Remotely: `https://weworkremotely.com/remote-jobs/search?term=QUERY`
- Greenhouse public boards: `https://boards.greenhouse.io/COMPANY`
- Lever public boards: `https://jobs.lever.co/COMPANY`
- Company career pages found via `search`

LinkedIn often requires a sign-in to see a full posting; prefer a public listing elsewhere if the page is gated. Still no applying and no account creation.
