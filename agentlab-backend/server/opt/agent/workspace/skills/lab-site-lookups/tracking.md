# Official package tracking pages (no account)

Use the **official** carrier page. Do not use a random unofficial tracker. You do not need an account to open the form or (usually) to see a status for a valid number.

Official tracking pages:

- USPS: `https://tools.usps.com/go/TrackConfirmAction` (or `https://www.usps.com/search/track-and-confirm.htm`)
- UPS: `https://www.ups.com/track`
- FedEx: `https://www.fedex.com/fedextrack.html` or `https://www.fedex.com/en-us/tracking.html`

To track a number Rick provided: prefer the official URL with the number in the query if the carrier documents it, or open the page and use the public form (`agent_load_browser` only if a plain fetch cannot show status). Report the status text, the official URL, and the time. Never invent a delivery date.
