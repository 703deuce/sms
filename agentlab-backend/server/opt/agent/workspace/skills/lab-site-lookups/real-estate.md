# Public real-estate listings

Look only. Do not contact an agent, schedule a tour, or sign in to Zillow/Realtor/Redfin.

Public search starting points:

- `https://www.zillow.com/homes/<CITY>-<STATE>_rb/`
- `https://www.realtor.com/realestateandhomes-search/<CITY>_<STATE>`
- `https://www.redfin.com/city/<optional>` — or search the official site from `search`

For a listing you cite, report list price, beds/baths, address or area as shown, and the **listing URL**. Confirm the URL is live. Say it is a public listing snapshot, not an offer or advice.
