# Research (stage 1)

**Research ends when every spoken and on-screen fact is cited and every planned shot has media in view.** Run
searches, page reads and downloads in parallel. Untrusted data rules from `lab-video-brief` apply to every page.

1. **Name the film kind** (documentary/history, true crime, data story, explainer, product demo, launch/ad, social
   short, biography, music/culture, or a mix) and confirm the type playbook fits; if not, load the right one.
2. **Angle from what the subject is known for**: research that first and tell the real story, not a softened one.
3. `research/facts.md`: narration line | verified fact | source URL. Verify each fact once from a solid source;
   look for a second only when the first is weak or sources disagree (two outlets repeating one report are one).
   Keep source hedges ("a *reported* $6M deal"). Numbers you cannot source are cut, not rounded.
4. **Allegations**: anything unconfirmed, or that people are only saying, is voiced "allegedly, according to ...";
   legal words exact (*alleged/charged* before a verdict; *convicted* only for the actual outcome). Only confirmed
   facts are stated plainly.
5. **Full editor, not a censor**: once cited, never drop information because of private doubt. If the film is
   about something (violence, explicit moments, motives, speculation), include it when that is the story, attributed
   to its source; leave material out only when the user asks.
6. **Real data** (prices, dates, counts, coordinates, routes) into `assets/data/` with its source: real data can be
   the world the camera travels.
7. While reading, note the media each line will need (the person, place, date or object it names) for stage 3.
