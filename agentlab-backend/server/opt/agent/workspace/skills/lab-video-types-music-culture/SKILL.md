# Type playbook: Music and celebrity culture explainers

Must = fails review if broken. Should = default; break it on purpose with one line in `log/job.md`. Freedom = open.
Full playbook (hook, structure, pacing, layout, captions, audio, transitions, mistakes) and sources: `reference.md`.

**Hook.** A recognisable face or sound in the first 90 f. People on screen early help [ABCD].

**Must**
- No vocals under speech, or duck ≥ 20 dB.
- Inserts on phrase boundaries.
- Facts sourced and hedged.
- Safe box; TP ≤ −1 dBTP.

**Should**
- Montages cut to musical phrases.
- A recognisable face or sound by 90 f.

**Freedom**
- Era-specific art direction, type and colour.

### Type checklist, run with the all-types C0 (`lab-video-review`) on change-point stills before render: Music / culture (C5)
- [ ] No sung vocal under narration (or ducked ≥ 20 dB).
- [ ] Inserts on phrase boundaries.
- [ ] Dates and figures are on screen and sourced.
