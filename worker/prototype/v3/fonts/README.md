# Clipper render fonts

- **Poppins-ExtraBold.ttf** — bundled in repo for default caption presets.
- **Montserrat-Black.ttf** — polished caption preset (`Montserrat Black` in ASS). Not committed as a binary; the worker image copies from Debian `fonts-montserrat` during Docker build (`worker/Dockerfile`).

Local dev without the image: install `fonts-montserrat` or place `Montserrat-Black.ttf` here manually.
