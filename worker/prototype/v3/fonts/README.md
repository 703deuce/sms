# Clipper render fonts

- **Poppins-ExtraBold.ttf** — bundled in repo for default caption presets.
- **Montserrat-Black.ttf** — polished caption preset (`Montserrat Black` in ASS). Not committed as a binary; the worker image downloads it during Docker build (`worker/Dockerfile`).

Local dev without the image: place `Montserrat-Black.ttf` here manually (Google Fonts static Black).
