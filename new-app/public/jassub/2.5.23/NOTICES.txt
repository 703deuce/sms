Transovo clip editor - subtitle renderer third-party notices
==========================================================

The clip editor preview renders captions, titles, hooks, text items and badge text with
JASSUB 2.5.23 (https://github.com/ThaUnknown/jassub, npm "jassub@2.5.23",
integrity sha512-KvWvkZOQvLUZKDoJTfAZzbmxCN2Avs37d1VnZlscKvmfPIjcS+l2guou0WdGW6z/+Uxb8F7ha8Nrq5h5+k9cLw==).

Files in this directory
- jassub-worker.wasm, jassub-worker-modern.wasm : copied UNMODIFIED from the npm package
  (dist/wasm/). They are separate files loaded at runtime and can be replaced by a user-built
  copy of the same version (LGPL-2.1 section 6). Build scripts and sources: the published
  package https://registry.npmjs.org/jassub/-/jassub-2.5.23.tgz and the project repository
  https://github.com/ThaUnknown/jassub (Dockerfile / Makefile, lib/ submodules incl. FriBidi);
  FriBidi 1.0.16 source: https://github.com/fribidi/fribidi/releases/tag/v1.0.16.
  On request we provide the corresponding source for the LGPL component.
- jassub.mjs, jassub-worker.js : the package's JavaScript (dist/jassub.js, dist/worker/*,
  dist/wasm/jassub-worker.js) bundled with esbuild 0.25, otherwise unmodified, except that the
  "rvfc-polyfill" import is replaced by an empty module (the editor never attaches a <video>).
- default.woff2 : Liberation Sans fallback shipped by JASSUB (SIL OFL 1.1).
